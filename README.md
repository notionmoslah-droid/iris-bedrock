LIRS — Lightweight Iris Resource System

An experimental resource pack inspection and compatibility library for Minecraft Bedrock Edition.

Vision

LIRS aims to provide a centralized library for discovering, inspecting, organizing, and documenting visual resource packs.

Features

- Resource pack manifest inspection.
- Compatibility metadata.
- Resource pack library.
- PBR and Vibrant Visuals support analysis.
- Preservation of original resource pack files.
- Automated testing through GitHub Actions.

Important

LIRS does not convert Java Edition Iris shaders into Bedrock shaders.

It does not guarantee that every Java shader or Bedrock resource pack will work.

Actual visual rendering depends on Minecraft Bedrock's rendering engine, device capabilities, and supported resource pack features.
